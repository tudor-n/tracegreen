# Rules for the SPA (`web/`)

- The SPA renders. It never computes carbon or KPIs; every number comes from the API. Formatting is presentation and lives in selectors and helpers: tonnes with one decimal (the API sends kg), euros without decimals, days as integers.
- React Flow state: Zustand (`web/src/store/`) owns the domain nodes. React Flow gets derived, memoised arrays from selectors. React Flow node objects, positions and change events are never written back into the store.
- The hotspot ring is a derived overlay (top N by `carbonKg`), never a node status. Status is `ESTIMATED | PARTIAL | VERIFIED`.
- Labels a juror reads come from `web/src/copy/`, never inline strings. Every AI-derived value is labelled, and lane cost and lead time are labelled illustrative.
- `dangerouslySetInnerHTML` is a lint error; render invoice text as text.
- Every component that shows data has a loading, an empty and an error state.
- API types come from `web/src/api/schema.d.ts` (generated by `pnpm gen:api`, aliased in `client.ts`); never hand-write them.
- Checks: `pnpm typecheck && pnpm lint && pnpm test` from `web/`.
